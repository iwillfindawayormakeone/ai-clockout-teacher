# The Orange's HOA website

The website for The Orange's Homeowners Association, Silver Spring, Maryland (33 homes).

Plain files, no build step. Vercel serves this folder as it is.

- `index.html` is the whole site. `site.css`, `site.js`, `content.js` and `scene.js` are its style, behavior, content and the seasonal picture.
- `board-guide.html` is the guide and FAQ for the board.
- `jobs.html` shows each board job, what the site does for it, and ready-made letters.
- `setup.html` has the one-time setup steps and the Gmail script that turns forwarded emails into posts.

The lists the board would change (meetings, county holidays, notes) are at the top of `content.js`.
